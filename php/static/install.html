Willkommen bei open-qr

Dein eigener QR-Code-Generator mit änderbaren Zielen und Scan-Statistik. Drei kurze Schritte, dann geht's los.

    Dein Admin-Konto

    Damit meldest du dich später an. Das Passwort wird nur gehasht gespeichert.

    Adresse & Datenbank

    Die Adresse steckt später in jedem QR-Code. Bei SQLite musst du nichts weiter einrichten.

    Alles bereit!

    open-qr läuft. Du bist schon angemeldet. So geht es weiter:

    1. QR-Code anlegenName und Ziel-URL eingeben – fertig ist der Code.
    2. Drucken & teilenAls PNG oder SVG herunterladen. Der Code zeigt auf deinen Kurz-Link.
    3. Ziel jederzeit ändernDer gedruckte Code bleibt gleich, nur das Ziel wechselt.
    4. Scans verfolgenTage, Wochen, Geräte – ohne Tracking-Cookies.
